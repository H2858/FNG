# Ninja Bot 🍉

أداة Android بلغة Kotlin تقوم بتقطيع الفواكه تلقائيا في لعبة Fruit Ninja **مع تجنّب القنابل**.

## كيف تعمل

1. **`ScreenCaptureService`** — تلتقط الشاشة مباشرة عبر `MediaProjection`.
2. **`FrameAnalyzer`** — يحلل كل إطار ملتقط ويكتشف الأجسام حسب اللون:
   - فاكهة = لون مشبّع وساطع (أحمر/أصفر/أخضر/برتقالي...).
   - قنبلة = لون قاتم رمادي/أسود منخفض التشبع.
3. **`SlicePlanner`** — يبني خطوط تقطيع تمر عبر الفواكه فقط، ويتحقق رياضيا
   أن كل خط سحب يبتعد عن مركز أي قنبلة بمسافة أمان كافية (نصف قطر القنبلة + هامش).
4. **`NinjaAccessibilityService`** — تنفّذ حركة السحب (swipe) الفعلية على الشاشة
   عبر `dispatchGesture`، تماما كما يفعل إصبع اللاعب.

## التشغيل

1. ثبّت التطبيق على هاتفك (عبر Android Studio أو APK من GitHub Actions).
2. افتح التطبيق واضغط "فعّل خدمة إمكانية الوصول" وفعّلها من إعدادات النظام.
3. اضغط "ابدأ التقطيع التلقائي" ووافق على إذن التقاط الشاشة.
4. افتح لعبة Fruit Ninja — ستبدأ الأداة بتقطيع الفواكه تلقائيا وتجنّب القنابل.

## البناء عبر GitHub Actions

يحتوي المشروع على `.github/workflows/android.yml` الذي يبني ملف APK تلقائيا
عند كل push على فرع `main`، ويرفعه كـ Artifact قابل للتحميل من تبويب Actions.

## ملاحظة مهمة

هذه الأداة مخصصة للتجربة الشخصية على جهازك الخاص فقط (لعبة أوفلاين لاعب واحد).
دقة الكشف تعتمد على ألوان اللعبة والإضاءة، وقد تحتاج لتعديل عتبات الألوان
في `FrameAnalyzer.kt` (`saturation`, `brightness`) حسب سمة اللعبة (Theme)
التي تستعملها.
